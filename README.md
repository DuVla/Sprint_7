# Sprint_7 - API Testing Project

## 📋 Описание
Полный проект по автоматическому тестированию API сервиса Яндекс Самокат (Ez-scooter).
Тесты написаны на Python с использованием pytest и включают Allure reporting.

## ✨ Особенности
- 22 автоматических теста
- Параметризированные тесты (для цветов заказов)
- Auto cleanup (автоматическая очистка тестовых данных)
- Independent tests (все тесты независимы)
- Allure HTML отчёты
